# Evil's Media Optimizer 4.6.2

## Banner quality hotfix

The experimental generated theme banners have been disabled because they did
not meet EMO's visual quality standard.

Every theme now uses the original polished Evil's Media Optimizer header
artwork. Theme colours still change normally through Settings → Appearance.

This is a temporary quality-first decision until individually designed
production-grade theme banners are ready.


## Queue reliability hotfix

Version 4.6.2 fixes the processing queue so completed jobs automatically advance to the next queued movie.
