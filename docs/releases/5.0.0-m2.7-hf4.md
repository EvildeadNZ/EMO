# EMP 5.0.0-m2.7-hf4 — Process Safety & System Tray Hotfix

## What changed

- EMP can no longer close while a movie is actively being processed.
- Closing during active processing now offers:
  - **Finish current movie, then exit**
  - **Keep processing**
  - **Minimize to hidden icons**
- If exit is requested, the current movie is allowed to complete its copy → encode → verify workflow before EMP closes.
- A Windows system-tray icon provides **Restore EMP** and **Exit EMP** controls.
- Tray exit uses the same process-safety protection as the main window close button.

## Why this helps

An accidental close can no longer interrupt an active movie job. EMP can also be left running in the Windows notification area's hidden icons while the current movie continues.

## Technical note

The implementation uses Qt's `QCloseEvent` handling to reject unsafe close requests and `QSystemTrayIcon` for the notification-area integration.
