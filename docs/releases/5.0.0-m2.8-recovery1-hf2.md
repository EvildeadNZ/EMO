# EMP 5.0.0-m2.8-recovery1-hf2 — HandBrake Bitrate Calculation Hotfix

## Release details

- **Tag:** `v5.0.0-m2.8-recovery1-hf2`
- **Release title:** **EMP 5.0.0-m2.8-recovery1-hf2 — HandBrake Bitrate Calculation Hotfix**
- **Status:** Recovery test candidate; do not publish until the Windows queue test passes.

## What changed

- Corrects EMP's target-bitrate calculation for size-targeted encoding.
- The recovered formula divided movie duration by 1000 before dividing target bits, inflating the requested kbps by approximately 1,000,000x.
- The corrected formula converts the final bits-per-second result to kbps in the proper direction.
- Keeps the HF1 `subprocess.list2cmdline` correction that allows HandBrake to launch.
