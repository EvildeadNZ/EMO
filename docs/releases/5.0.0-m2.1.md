# EMP 5.0.0-m2.1 - Easier Jellyfin Setup

This update removes one of the more awkward setup steps in EMP: manually hunting down a Jellyfin API key.

## What you will notice

Open **Settings > Integrations** or rerun the **Platform Builder** and you will now see **Connect to Jellyfin**.

Enter:

- Your Jellyfin server address
- Your Jellyfin username
- Your Jellyfin password

Click **Connect to Jellyfin** and EMP authenticates directly with your Jellyfin server. Jellyfin returns an access token and EMP fills the API credential automatically.

## Your password is not saved

EMP uses the password only for the login request. After a successful connection the password field is cleared, and the password is not written to `config.json`.

EMP stores the access token Jellyfin returns so it can keep using features such as connection testing and poster/library access without asking you to sign in every time.

## Existing setups still work

If you already pasted a Jellyfin API key into EMP, you do not need to change anything. Manual API keys remain supported.

## Why we changed it

Previously a new EMP user had to leave EMP, open the Jellyfin administration dashboard, find the API key area, create or copy a key, return to EMP, and paste it into Settings. The new connection flow turns that into a normal sign-in and makes the first-run Platform Builder much easier to understand.

## Technical note

The connection uses Jellyfin's user authentication flow to obtain an access token. It does not scrape credentials or read Jellyfin's files directly.
