# EMP 5.0.0-m2.8-foundation2

## Release title

EMP 5.0.0-m2.8-foundation2 — About, Credits & Licence Visibility

## Purpose

Make EMP's public identity, open-source licence and third-party technology attribution visible from inside the application before work begins on wider public distribution.

## Changes

- Replaces the personal About message at runtime with a dedicated public-facing EMP dialog.
- Adds four About-dialog tabs: About, Credits, EMP Licence, and Third-Party Licences.
- Clearly identifies the product as **Evil's Media Encoding Platform (EMP), powered by EMO — Evil's Media Optimizer**.
- States that EMP is GPL-3.0-or-later free software and is provided without warranty, with the complete installed licence available in-app.
- Credits HandBrake/HandBrakeCLI as the external transcoding engine used by EMP.
- Credits FFmpeg/ffprobe for external media inspection.
- Credits Qt for Python/PySide6, psutil, Pillow, NVIDIA NVENC and Jellyfin where relevant.
- Clearly states that third-party technologies remain separate projects and are not owned by EMP.
- Adds Jellyfin to `THIRD_PARTY_NOTICES.md` and records that EMP communicates with a separately configured Jellyfin server through its API.
- Wires the new About dialog into both normal (`EvilsMediaOptimizer.pyw`) and console/troubleshooting (`app.py`) launch paths.

## Safety / behavioural impact

- No encoding command construction changed.
- No scan logic changed.
- No queue logic changed.
- No media copy/replacement logic changed.
- No updater logic changed.
- The new module passed Python syntax compilation before merge review.

## Version note

The executable `APP_VERSION` is deliberately not changed in this patch. The repository still needs a separate reconciliation of the active app version because `emo/version.py` reports `5.0.0-m2.4` while later m2.7-hf4 patch material exists in the repository.
