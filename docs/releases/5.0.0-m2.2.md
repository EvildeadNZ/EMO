# EMP 5.0.0-m2.2 - Adjustable UI Text Size

## What this update does

EMP now includes a **UI Text Size** control under **Settings → Appearance**.

The slider runs from **85% to 150%**, with **100%** matching the normal EMP interface size.

## Why this was added

EMP displays a lot of useful information at once. On high-resolution monitors, smaller screens, TVs, or displays positioned further away, some of that text can be harder to read than it should be.

Instead of forcing users to change Windows display scaling for their entire PC, EMP can now scale its own interface text independently.

## How to use it

1. Open **Settings**.
2. Select **Appearance**.
3. Move **UI Text Size** to the size you prefer.
4. Click **Save**.

EMP remembers the selected value and restores it automatically the next time it starts.

## What scales

The setting scales EMP's primary interface typography, including navigation labels, dashboard and status metrics, tables, buttons, status panels and other stylesheet-driven text.

Some artwork and fixed graphic elements intentionally remain the same size so the interface layout does not become distorted.
