## What changed

- Restored the later EMP 5 working source recovered from the August 16 development build.
- Restored the multi-file queue snapshot/lifetime fix so a queue continues beyond the first completed movie.

- Restored process-safe closing and Windows system-tray behaviour from the `m2.7-hf4` lineage.
- Restored **Finish current movie, then exit**, **Keep processing**, and **Minimize to hidden icons** behaviour while a movie is active.
- Restored Platform Builder and guided Jellyfin connection/API-key setup.
- Restored adjustable UI text scaling, themes/banner handling and later update-status work.
- Restored the **Exclude Already Efficient** control.
- Restored the missing service-status traffic-light indicator.
- Restored the repaired encoding-calculation block from the August 16 fix.

## Why this release exists

The repository's version metadata and release documentation had advanced beyond the executable `main_window.py` stored on `main`. Several later working changes survived in patches and in the August 16 development source, while `main` had fallen back to an older code snapshot.

This recovery milestone establishes one truthful source baseline before EMP's bootstrap installer and public-distribution work continue.
