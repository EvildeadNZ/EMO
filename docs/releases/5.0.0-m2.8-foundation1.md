# EMP 5.0.0-m2.8-foundation1

## Release title

EMP 5.0.0-m2.8-foundation1 — Public Distribution Foundation

## Purpose

This is the first public-distribution readiness patch for Evil's Media Encoding Platform (EMP), powered by EMO. It establishes the licensing, attribution and project-documentation foundation needed before EMP is made easier to install or distributed more widely.

## Changes

- Declares EMP/EMO under GPL-3.0-or-later.
- Adds `THIRD_PARTY_NOTICES.md` covering the current relationship with HandBrake, FFmpeg/ffprobe, PySide6/Qt, psutil, Pillow and NVIDIA NVENC.
- Explicitly records that HandBrake, FFmpeg and NVIDIA binaries are not currently bundled by EMP.
- Rewrites the public README around the EMP 5 identity and current safety model.
- Adds the professional UI, bootstrap installer, donation/support and distribution-compliance work to the persistent roadmap.
- Adds a release packaging rule requiring third-party component/version and licence review before public installer releases.

## Behavioural impact

None. This foundation patch intentionally does not modify encoding, scanning, queue, replacement or updater behaviour.

## Version note

The repository's current `emo/version.py` still reports `5.0.0-m2.4`, while later m2.7-hf4 patch/release material exists in the repository. This foundation patch deliberately does **not** change `APP_VERSION` until the active application state and hotfix history are reconciled, preventing an accidental version regression or false version claim.
